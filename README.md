# 真车主组队完单活动后台原型

仓库包含：

- 后台配置原型：`index.html`、`styles.css`、`app.js`
- 后台配置说明：`后台配置说明.md`

## GitHub Pages 发布

1. 进入仓库的 `Settings`。
2. 在左侧选择 `Pages`。
3. 在 `Build and deployment` 中，将 `Source` 选择为 `Deploy from a branch`。
4. `Branch` 选择 `main`，目录选择 `/ (root)`，点击 `Save`。
5. 等待 GitHub 完成首次发布后，访问：`https://luyaoyi.github.io/driverTeam/`。

页面为纯静态原型，不需要构建命令。原型数据仅保存在当前浏览器内存中，刷新后恢复为示例数据。
